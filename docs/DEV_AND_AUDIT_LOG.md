## Блок 3. Монетизация **[B]**

Отдельный **чистый** коммит, не смешивать с музыкой и артом.

1. **Google Play Billing Library** (или RuStore Billing, если цель — RuStore в первую очередь; можно оба позже).
   - SKU:  
     - Series pack (истории 11–50)  
     - PRO (всё + без рекламы)
   - Acknowledge покупок, restore, обработка already-owned.
2. **Реклама:** AdMob или Yandex Mobile Ads.
   - Rewarded на пачку `+5`.
   - Interstitial по текущей логике «раз в N чтений» — только если это продуктово нужно; не перегружать.
3. **Manifest:**
   - `INTERNET`
   - ad network `meta-data` (App ID)
   - при необходимости `AD_ID` / privacy declarations под политику стора
4. **Состояние покупок:**
   - Не полагаться только на голый SharedPreferences.
   - Минимум: писать флаги после успешного Billing callback; restore при старте.
   - Лучше: EncryptedSharedPreferences или аналог + сверка с Billing при launch.
5. Удалить/изолировать симуляцию (`buyFullVersion()` / `completeAdSlot()` без SDK) так, чтобы в release-сборке не было «фейкового PRO» с кнопки.

**Критерий готовности:** на тестовом треке Play/RuStore реальная тестовая покупка и rewarded callback открывают контент; после переустановки restore восстанавливает доступ.

## Блок 4. Саундтрек (желательно до v1.0, можно 1.1)

Отдельный коммит, когда будут 4 трека (OGG ~3 мин, ACE-Step / Suno).

1. Модуль плеера (не размазывать по UI):
   - play / pause / stop
   - `AudioFocus` request/abandon
   - пауза в `onStop` / при уходе в фон
   - не держать час аудио в RAM: один трек или короткая ротация 3–4 файлов
2. HUD читалки: тихая громкость по умолчанию, выключатель «музыка вкл/выкл», состояние помнить в prefs.
3. Не блокировать UI; ошибки загрузки трека — тихий fallback без краша.
4. Вес: OGG, не раздувать APK; при необходимости — on-demand / только 1–2 трека в v1.0.

**Критерий готовности:** музыка играет в читалке, молчит в фоне, не мешает системе, тест на вкл/выкл есть или ручной чеклист пройден.
