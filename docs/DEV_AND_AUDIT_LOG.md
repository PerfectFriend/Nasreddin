## 3. Журнал аудитов (Audit Trail)

### Round 0 — Авторский самоаудит перед открытием репозитория ревьюерам
- **Дата:** `2026-11-14`
- **Статус:** ✅ Завершено и проверено (`compile_applet` OK, `gradle :app:testDebugUnitTest` — **11/11 PASS**)

| ID | Модуль / Область | Найденная проблема | Принятое решение | Статус |
| :--- | :--- | :--- | :--- | :--- |
| **A0-01** | `ComicReaderScreen` | В режиме вертикального скролла (`VERTICAL_SCROLL`) `LaunchedEffect` слушал только `pagerState.currentPage`, из-за чего прогресс чтения и `ComicLoreSheet` не обновлялись при прокрутке. | Единый `LaunchedEffect(readingMode, pagerState, verticalListState)` отслеживает оба режима (`firstVisibleItemIndex` / `currentPage`). | ✅ Fixed |
| **A0-02** | `ComicViewModel`, `SplashScreen` | Toast/Snackbar-сообщения (импорт папки/файлов, сохранение порядка, удаление) и `contentDescription` заставки были зашиты только на русском языке. | Все строки вынесены в `AppStrings` с поддержкой `RU / ES / EN`; добавлен Robolectric-тест на все 3 языка. | ✅ Fixed |
| **A0-03** | `ZoomableComicImage` | Отсутствие ключа `page.id` в `remember` могло переносить зум/панорамирование на следующую страницу. | Использован `remember(page.id)` для `scale` и `offset`. | ✅ Fixed |
| **A0-04** | `PaywallDialog`, `MainActivity` | После покупки серии `11–25` (`seriesUnlocked == true`) диалог апгрейда до `PRO` всё ещё показывал кнопки серии и рекламы. | В `PaywallDialog` передан `seriesUnlocked`; лишние CTA автоматически скрываются. | ✅ Fixed |
| **A0-05** | `ComicRepository`, `FolderImporter`, `ComicPageArtwork` | Пустые `catch (_: Exception) {}` молча глотали ошибки парсинга JSON, SAF URI и кроп-декодинга. | Все блоки перехвата заменены на явное логирование (`Log.w` / `Log.e`). | ✅ Fixed |
| **A0-06** | Кодовая база (все модули) | Недостаточно архитектурных пояснений для быстрого онбординга внешних ИИ-ревьюеров. | Добавлены KDoc-блоки на экраны, кеши, `ViewModel`, `Repository` и точки будущей интеграции SDK. | ✅ Fixed |
